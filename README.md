# Cloud Engineering Starter

This repository documents my journey into **Cloud Engineering**.

It brings together the fundamental skills, concepts, exercises, and practical work I am developing throughout my learning journey.

The goal is to build strong foundations in **Python, Linux, Bash, system administration, networking, Git, and cloud technologies**, while progressively applying these skills through practical exercises and projects.
